## 📌 About the Project

**Fabric** is an interactive clothing customization application designed to help users explore clothing styles and experiment with different fabric textures.

Users can select a clothing model, choose a fabric from the available options, and preview how the selected texture looks on the chosen model.

The application combines a clean interface with interactive components to create a simple and engaging visual experience.

## ✨ Features

* 👔 **Clothing Model Selection** — Choose from coats, vests, jackets, trousers, shirts, ties, and blazers.
* 🎨 **Fabric Gallery** — Browse and select from a collection of fabric textures.
* 🧵 **Interactive Fabric Preview** — View the selected fabric texture applied to the selected clothing model.
* 🔄 **Dynamic Selection** — Change clothing models and fabric options interactively.
* 🖼️ **Image Masking** — Uses CSS image masking to display fabric textures within clothing silhouettes.
* 🧭 **Easy Navigation** — Return to the main page using the navigation button.
* 💻 **Modern Interface** — Styled with Tailwind CSS utility classes.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* npm

### Installation

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd YOUR_PROJECT_FOLDER
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal, usually provided by Vite, to view the application in your browser.

## 🧵 How to Use

1. Open the application.
2. Select a clothing model from the **Models** section.
3. Browse the available fabrics.
4. Select a fabric texture.
5. View the fabric applied to the selected clothing model.
6. Change your selections to explore different combinations.
7. Use **Back to Main** to return to the main page.
